# ระบบปฏิทินการปฏิบัติงาน (Work Calendar System)

เว็บแอปพลิเคชันจัดการปฏิทินและกำหนดการปฏิบัติงานสำหรับสถาบัน/องค์กร ภาษาไทยทั้งระบบ แสดงผลปีเป็น **พ.ศ.** รองรับการใช้งานบนมือถือ (Responsive) โหมดมืด (Dark Mode) และใช้ **Google Sheets** เป็นฐานข้อมูลผ่าน **Google Apps Script Web App (JSON API)**

---

## 📁 โครงสร้างโปรเจกต์

```
ระบบปฏิทินการปฏิบัติงาน/
├── Code.gs        ← Google Apps Script Backend (API, Data Handler & Email Trigger)
├── index.html     ← Frontend Web App (HTML5 + CSS3 + Vanilla JS แบบ Single File)
└── README.md      ← คู่มือการติดตั้ง ใช้งาน และ API Documentation
```

## ✨ ฟีเจอร์หลัก (Features)

1. **ปฏิทินการปฏิบัติงาน 3 มุมมอง (Calendar Views)**
   - **มุมมองเดือน (Month View):** แสดงตาราง 7 วัน (อา-ส) ไฮไลต์วันหยุดราชการ/เสาร์-อาทิตย์ พร้อมแถบงานสีตามประเภท รองรับงานข้ามหลายวัน (Multi-day events)
   - **มุมมองสัปดาห์ (Week View):** แสดงตารางเวลา 00:00 - 23:00 น. จัดตำแหน่งตามเวลาเริ่ม-สิ้นสุด
   - **มุมมองวัน (Day View):** กำหนดการปฏิบัติงานละเอียดรายชั่วโมงตลอดทั้งวัน
   - **ตัวกรอง (Filters):** กรองตามผู้รับผิดชอบ, ประเภทงาน, และสถานะงาน
   - **ปีแสดงเป็น พ.ศ.:** แปลงปี ค.ศ. สู่ พ.ศ. (ค.ศ. + 543) ในทุกหน้าจอ

2. **การจัดการงาน (Task Management)**
   - เพิ่ม/แก้ไข/ลบงาน พร้อมฟอร์มระบุชื่องาน, วันที่, เวลา, ผู้รับผิดชอบ, สถานที่ และรายละเอียด
   - **เปลี่ยนสถานะทันที (Quick Status Change):** ปรับสถานะงาน (`todo`, `doing`, `done`) ได้จาก Popup รายละเอียดงานทันที

3. **ระบบสิทธิ์ผู้ใช้งาน (Role-Based Access Control - RBAC)**
   - 🧑‍💻 **staff (เจ้าหน้าที่):** ดูปฏิทินงานทั้งหมด และสามารถแก้ไข/ลบได้เฉพาะงานที่ตนเองเป็นผู้รับผิดชอบ
   - 👔 **head (หัวหน้าแผนก):** ดูงานและจัดการงานของสมาชิกทุกคนในแผนกตนเองได้
   - 👑 **admin (ผู้ดูแลระบบ):** จัดการงานได้ทั้งหมด จัดการบัญชีผู้ใช้ และจัดการวันหยุดนักขัตฤกษ์

4. **การแจ้งเตือน (Notifications & Reminders)**
   - **In-App Notification:** สัญลักษณ์กระดิ่งพร้อม Badge แสดงจำนวนงานที่ใกล้ครบกำหนดส่งภายใน 3 วัน
   - **Email Reminder:** ส่งอีเมลแจ้งเตือนงานที่ใกล้ถึงกำหนดเข้า Gmail ของผู้รับผิดชอบอัตโนมัติทุกวันเวลา 08:00 น. ผ่าน Time-driven Trigger ใน Google Apps Script

5. **แดชบอร์ดและการส่งออกข้อมูล (Dashboard & Export)**
   - การ์ดสรุปจำนวนงาน: งานทั้งหมด, รอดำเนินการ, กำลังดำเนินการ, เสร็จสิ้นแล้ว, เกินกำหนดส่ง
   - ตารางสรุปภาระงานแยกตามรายบุคคลและแผนก
   - ตารางงานที่ใกล้ถึงกำหนดส่งภายใน 7 วันข้างหน้า
   - **ส่งออก Excel (CSV):** มี UTF-8 BOM รองรับภาษาไทยใน Microsoft Excel อย่างสมบูรณ์
   - **ส่งออก PDF:** รองรับการพิมพ์และการบันทึกเป็น PDF สวยงามด้วย Print Stylesheet

6. **รองรับ Dark Mode & Responsive**
   - สลับธีมมืด/สว่างได้ตลอดเวลา และบันทึกการตั้งค่าลง `localStorage`
   - รองรับหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์อย่างลื่นไหล

7. **ระบบเชื่อมต่อ 2 โหมด (Hybrid Mode)**
   - **Demo Mode (Offline):** ทดสอบและใช้งานได้ทันทีโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ใช้ข้อมูลจำลองบน `localStorage`
   - **Live Google Sheets Mode:** ซิงก์ข้อมูลสองทิศทางกับ Google Spreadsheet ผ่าน Google Apps Script

## 🚀 ขั้นตอนการ Deploy บน Google Apps Script

### ขั้นตอนที่ 1: สร้าง Google Sheets

1. เข้าไปที่ [Google Sheets](https://sheets.google.com) และสร้าง Spreadsheet ใหม่
2. ตั้งชื่อไฟล์ เช่น **"ระบบปฏิทินการปฏิบัติงาน"**
3. ไม่จำเป็นต้องสร้างตารางด้วยตนเอง ระบบจะสร้างชีต **Events**, **Users**, และ **Holidays** พร้อมข้อมูลตัวอย่างให้อัตโนมัติในขั้นตอนถัดไป

### ขั้นตอนที่ 2: ติดตั้ง Code ใน Apps Script

1. ใน Google Sheets ให้คลิกเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs` ในโปรเจกต์นี้ไปวางแทนที่
4. กดปุ่ม **บันทึกโครงการ (Save / Ctrl+S)**

### ขั้นตอนที่ 3: รันสร้างข้อมูลตัวอย่าง (Init Sample Data)

1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `initSampleData` จาก Dropdown
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. Google จะขอสิทธิ์การเข้าถึง (Authorization Required) ให้คลิก **ตรวจทานสิทธิ์ (Review permissions)** → เลือกบัญชี Google → **ขั้นสูง (Advanced)** → คลิก **ไปยัง... (ไม่ปลอดภัย) / Go to... (unsafe)** → กด **อนุญาต (Allow)**
4. เมื่อทำงานเสร็จ Spreadsheet ของคุณจะมี 3 ชีตพร้อมข้อมูลตัวอย่าง:
   - `Users`: บัญชีตัวอย่าง 5 รายการ (Admin, Head IT, Head HR, Staff IT, Staff HR)
   - `Holidays`: วันหยุดไทย ปี 2568 (19 รายการ)
   - `Events`: งานตัวอย่าง 10 รายการ

### ขั้นตอนที่ 4: ตั้งค่า Email Reminder Trigger

1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `setupTrigger` จาก Dropdown
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. ระบบจะสร้าง Time-driven Trigger ที่จะทำงานอัตโนมัติทุกวันในเวลา 08:00 น. เพื่อตรวจสอบและส่งอีเมลแจ้งเตือนงานที่ใกล้ถึงกำหนด

### ขั้นตอนที่ 5: Deploy เป็น Web App

1. คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกไอคอนรูปฟันเฟือง ⚙️ ข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `ระบบปฏิทินการปฏิบัติงาน v1.0`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)** *(สำคัญ: เพื่อให้สิทธิ์เข้าถึง Spreadsheet เดียวกัน)*
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(เพื่อให้ Frontend เชื่อมต่อ API ได้)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เก็บไว้

## ⚙️ การตั้งค่า URL API บน Frontend

คุณสามารถตั้งค่า Web App URL ได้ 2 วิธีง่ายๆ:

### วิธีที่ 1: ตั้งค่าผ่านหน้าจอแอป (แนะนำ - สะดวกที่สุด)
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. เข้าสู่ระบบ (เช่น เลือก Admin หรือบัญชีใดก็ได้)
3. คลิกปุ่มฟันเฟือง **⚙️** บนแถบ Header ด้านขวาบน
4. วาง URL Web App ที่ได้จากขั้นตอนที่ 5 ลงในช่อง
5. คลิก **"🔍 ทดสอบเชื่อมต่อ"** แล้วกด **"💾 บันทึกการตั้งค่า"**
6. ระบบจะบันทึกลงในเบราว์เซอร์และดึงข้อมูลสดจาก Google Sheets ทันที

### วิธีที่ 2: แก้ไขในโค้ด `index.html` โดยตรง
เปิดไฟล์ `index.html` ค้นหาบรรทัดที่มี `apiUrl:` แล้ววาง URL ลงไป:
```javascript
const App = {
  apiUrl: 'https://script.google.com/macros/s/AKfycb.../exec',
  // ...
};
```

## 🛠️ รายละเอียด API Actions (Google Apps Script)

| Action | Method | Parameter สำคัญ | คำอธิบาย |
|:---|:---:|:---|:---|
| `ping` | POST/GET | - | ตรวจสอบสถานะการเชื่อมต่อ API |
| `getEvents` | POST/GET | `assignee`, `type`, `status`, `startDate`, `endDate` | ดึงรายการงานตามตัวกรอง |
| `createEvent`| POST | `title`, `type`, `status`, `assignee`, `start`, `end`, ... | เพิ่มงานใหม่ |
| `updateEvent`| POST | `id`, `title`, `status`, ... | แก้ไขข้อมูลงาน |
| `deleteEvent`| POST | `id` | ลบงานออกจากระบบ |
| `updateStatus`| POST | `id`, `status` (`todo`/`doing`/`done`) | เปลี่ยนสถานะงานทันที |
| `getUsers` | POST/GET | - | ดึงรายชื่อผู้ใช้ทั้งหมด |
| `createUser`| POST | `email`, `name`, `department`, `role` | เพิ่มผู้ใช้ใหม่ (เฉพาะ Admin) |
| `updateUser`| POST | `email`, `name`, `department`, `role` | แก้ไขข้อมูลผู้ใช้ (เฉพาะ Admin) |
| `deleteUser`| POST | `email` | ลบผู้ใช้ (เฉพาะ Admin) |
| `getHolidays`| POST/GET | `year` | ดึงรายการวันหยุด |
| `createHoliday`| POST | `date`, `name`, `type` | เพิ่มวันหยุด (เฉพาะ Admin) |
| `deleteHoliday`| POST | `date` | ลบวันหยุด (เฉพาะ Admin) |
| `getDashboard`| POST/GET | - | ดึงสถิติภาพรวมแดชบอร์ด |
| `initSampleData`| POST | - | สร้างโครงสร้างชีตและข้อมูลตัวอย่าง |
| `setupTrigger`| POST | - | ติดตั้ง Daily Email Trigger 08:00 น. |

## 💡 การแก้ปัญหาที่พบบ่อย (Troubleshooting)

1. **เชื่อมต่อ API ไม่ได้ หรือเกิดข้อผิดพลาด CORS:**
   - ตรวจสอบว่าในขั้นตอน Deploy Web App ได้เลือก **Who has access: Anyone** หรือไม่
   - ตรวจสอบว่า URL ที่นำมาใช้ลงท้ายด้วย `/exec` (ไม่ใช่ `/dev`)
2. **ข้อมูลใน Google Sheets ไม่ถูกสร้าง:**
   - เข้า Apps Script Editor และกดเรียกใช้ฟังก์ชัน `initSampleData` ด้วยตนเอง 1 ครั้ง
3. **ส่งอีเมลแจ้งเตือนไม่สำเร็จ:**
   - บัญชี Google ต้องให้สิทธิ์ MailApp ในการส่งอีเมลตอนรันฟังก์ชันครั้งแรก
   - ตรวจสอบโควตาการส่งอีเมลประจำวันของบัญชี Google Workspace หรือ Gmail ทั่วไป
